# Changelog

## v2.0.5

- Добавлено устойчивое сравнение триггеров после OCR: без учета пробелов и знаков.
- Исправлены частые OCR-ошибки при сравнении, например ы вместо и и пропавший пробел после вы.
- В лог теперь пишется режим совпадения триггера: exact или 
ormalized.

## v2.0.4

- При запуске программа показывает всплывающее уведомление, если доступна новая версия.
- В уведомлении отображается список изменений из GitHub Release.
- Добавлена отдельная кнопка скачивания ZIP-архива обновления.

## v2.0.3

- Добавлено диагностическое логирование в `logs/ems_logger.log` с ротацией файлов.
- Добавлена кнопка `Логи` для быстрого открытия папки с логами.
- В лог пишутся OCR-текст, найденные триггеры, cooldown, путь сохранения, ошибки захвата экрана и ошибки записи файла.
- Время в логах пишется по МСК для сопоставления с именами скриншотов.

## v2.0.2

- Исправлен общий cooldown: теперь задержка сохранения считается отдельно по каждой папке/действию.
- Ошибки сохранения и захвата экрана теперь показываются в статусе программы, а не только в консоли.
- Фоновый цикл больше не останавливается молча при временной ошибке захвата экрана.

## v2.0.1

- Исправлено сохранение скриншотов в папки с кириллицей и Unicode-символами в пути.

## v2.0

- Новый компактный темный интерфейс.
- Выбор области распознавания.
- Выбор монитора из списка подключенных экранов.
- Чтение области через OCR.
- Встроенный Tesseract OCR в релизной сборке.
- Зеленая индикация корректно распознанного текста.
- Красная индикация ошибок OCR.
- Сортировка скриншотов по московскому времени.
- Запоминание размера и позиции окна.
- Одноразовый дисклеймер при первом запуске.
- Кнопка пожертвований.
- Проверка обновлений через GitHub Releases.
