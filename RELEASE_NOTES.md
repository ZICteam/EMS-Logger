# EMS Logger v2.0.6

## Что нового

- Добавлен новый триггер `объявление`.
- Для объявлений используется отдельная папка `ads`.
- Сортировка работает по дню и ночи: `screenshots/day/ads` и `screenshots/night/ads`.
- У существующих пользователей новый триггер автоматически появится в настройках после запуска.

- Триггеры теперь сравниваются устойчивее после OCR.
- Программа больше не зависит от пробела в фразах вроде `вы реанимировали`: вариант `выреанимировали` тоже будет найден.
- Частая ошибка OCR `реанымировали` теперь сопоставляется с триггером `реанимировали`.
- Это помогает при растянутом/сглаженном игровом тексте, где Tesseract нестабильно распознает пробелы и отдельные буквы.

- При запуске программа теперь сразу показывает всплывающее уведомление, если доступна новая версия.
- В окне обновления отображается список изменений из GitHub Release.
- Кнопка `Скачать обновление` открывает ZIP-архив последнего релиза.

- Добавлено диагностическое логирование в `logs/ems_logger.log`.
- Добавлена кнопка `Логи` для открытия папки с логами.
- Лог помогает понять, почему скриншот не сохранился: OCR не нашел триггер, сработал cooldown, была ошибка захвата экрана или ошибка записи файла.
- Время в логах указывается по МСК.

- Исправлен общий cooldown, из-за которого разные действия могли не сохраняться в течение 15 секунд после предыдущего скриншота.
- Cooldown теперь считается отдельно для каждой папки/действия.
- Ошибки сохранения и захвата экрана теперь отображаются в статусе программы.

- Исправлено сохранение скриншотов в папки с кириллицей и Unicode-символами в пути.

## Основные возможности

- Полностью обновленный интерфейс.
- Выбор монитора и области OCR.
- Встроенный Tesseract OCR.
- Сортировка скриншотов по МСК.
- Настраиваемые фразы-триггеры и папки.
- Автоматическая проверка обновлений через GitHub Releases.
- Сохранение размера и положения окна.
- Дисклеймер при первом запуске.

## Установка

1. Скачайте `EMS_Logger_v2_0_6_Windows.zip`.
2. Распакуйте архив.
3. Запустите `EMS_Screen.exe`.
